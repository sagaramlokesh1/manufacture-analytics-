# 🏭 Manufacturing Analytics Project

## 📌 Project Overview
The Manufacturing Analytics Project focuses on analyzing manufacturing
and production data to monitor operational performance, production
efficiency, product quality, and manufacturing costs.

The project uses Excel and SQL for data preparation and analysis,
while Power BI and Tableau are used to build interactive dashboards
and visualize manufacturing KPIs.

## 🎯 Project Objectives
- Analyze overall production performance
- Monitor production quantity and manufacturing trends
- Identify production and quality issues
- Analyze rejection and defect rates
- Compare performance across products and departments
- Track manufacturing costs
- Develop interactive KPI dashboards
- Generate insights for operational decision-making
